# Velanera iOS — Feature Status

Application is **feature-complete** for development without a Mac.

1. AI Voice Concierge (host Hold to Talk, STT, TTS, suggestions, staff requests, archive, onboarding)
2. Restaurant (menu, wine/cocktails/desserts, chef, allergens, detail, favourites)
3. Lounge (VIP/private/bottle detail, DJs, private events, gallery, booking draft handoff)
4. Booking engine (availability slots, confirmation, manage/cancel, draft prefill)
5. Membership (card/QR, tier compare, mock checkout)
6. Events (list, filters, detail, RSVP)
7. Profile (Apple Sign In, Google placeholder, reservations, favourites, edit)
8. Settings (notifications, voice, dietary, privacy/terms in-app)
9. Home extras (hours, location, gallery)
10. Mock backend with stable IDs + expanded APIClient
11. iPhone 17 portrait / Dark Mode / ProMotion-oriented UI tokens
